# Издательская сборка

Финальные читательские версии собираются из файлов `chapter-01.md` — `chapter-34.md` и интерлюдии `interlude-smollett.md`. Интерлюдия автоматически ставится между главами 21 и 22.

Метаданные издания:

- название — «Если бы я вам рассказал про Сильвера»;
- авторы — Аскар Рахимбердиев, ChatGPT и Claude;
- источник — роман Роберта Льюиса Стивенсона «Остров сокровищ»;
- язык — русский;
- год первого электронного издания — 2026.

В PDF используются системные Georgia и Montserrat с запасным переходом на DejaVu. Для сборки нужны Python 3, Pillow и ReportLab.

```bash
python3 publication/build_book.py --front-preview
python3 publication/build_book.py --review-pdf
python3 publication/build_book.py --all
```

Готовые файлы создаются в `output/pdf/` и `output/epub/`. Временные файлы создаются в `tmp/` и после успешной сборки удаляются автоматически. Мастер-иллюстрации остаются полноразмерными PNG для будущей переработки. Для PDF сборщик создаёт отдельные JPEG-копии с честным разрешением 300 dpi относительно книжной полосы; для EPUB — экранные JPEG-копии с максимальной стороной 1600 пикселей. Это сохраняет нужное каждому формату качество и не раздувает готовые книги десятками мегабайт.

В текущей читательской сборке используются 22 внутренние иллюстрации в главах 1, 3, 4, 6–9, 11, 13–15, 17, 18, 20–22, 24, 26, 28, 30, 32 и 34. Каждая картинка привязана к конкретному абзацу изображённой сцены и встраивается во всю ширину полосы внутри главы, а не ставится отдельным листом перед её заголовком. Если текст якорного абзаца изменится, сборка остановится с явной ошибкой вместо того, чтобы молча перенести картинку не туда. Отбракованные кадры к главам 23, 29 и 33 в книгу не входят. Исходная живописная обложка хранится отдельно от версии с типографикой, поэтому заголовок и авторские строки можно менять без перегенерации рисунка.
